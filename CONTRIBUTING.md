# Contributing

This repository accepts compact provenance, schema, and aggregate-evidence
improvements. Please keep report bodies, prompt/answer/completion text, traces,
credentials, official competition rows, and third-party copies out of this
release.

## Cite this repository

Use GitHub's **Cite this repository** action, or copy the canonical entry from
[`CITATION.bib`](CITATION.bib) / [`CITATION.cff`](CITATION.cff). Cite the
official Kaggle competition separately when discussing its source data.
